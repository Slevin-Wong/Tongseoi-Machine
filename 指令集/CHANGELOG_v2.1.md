## 🔄 调整1：支持大批量需求 + 自动分段输出

### 问题
原版只支持20-30个创意，无法满足用户要求100-200条创意的需求

### 解决方案
**文件**：`stage1_workflow_rewrite.md`

**新增功能：**
1. **自动分段输出机制**
   - 当用户要求100条以上创意时，LLM根据自身token限制自动分批输出
   - 示例：200条创意分为4批，每批50条
   
2. **进度提示**
   - 每批结束后显示："已完成 50/200，输入'继续'获取下一批"
   - 保持编号连续性（不重复编号）

3. **条数承诺**
   - 必须完成用户要求的总数
   - ❌ 用户要200条，只给30条就停止
   - ✅ 分批输出，直到完成200条

4. **简化策略**
   - 超过100条时，可适当精简描述（40-60字/概念）
   - 但7个必选维度仍需全部包含

**使用示例：**
```
用户："给我200个创意"

LLM响应：
[概念001] xxx
[概念002] xxx
...
[概念050] xxx

已完成 50/200，输入'继续'获取下一批

用户："继续"

LLM继续：
[概念051] xxx
...
[概念100] xxx

已完成 100/200，输入'继续'获取下一批
```

## 🌐 调整2：支持中文Prompt + 合理字数要求

### 问题
原版只支持英文prompt（900+字符），不支持中文

### 解决方案
**文件**：`stage1_workflow_rewrite.md`

**新增功能：**

1. **多语言支持**
   - 英文prompt：900+字符（约150-180个英文单词）
   - 中文prompt：400+字符（约200-250个中文字）
   - 中英双语：两种都提供

2. **字数差异原因**
   - 中文表达更精炼，信息密度更高
   - 1个中文字 ≈ 2-3个英文字符的信息量
   - 因此中文prompt字数约为英文的45%

3. **技术前缀保持不变**
   - 英文：`masterpiece, best quality, hyper-realistic photo, 8k, UHD,`
   - 中文：`杰作，最佳质量，超写实照片，8K，超高清，`

4. **三种输出格式**
   - 格式A：纯英文（默认）
   - 格式B：纯中文（用户要求时）
   - 格式C：中英双语（用户要求时）

5. **中文内容结构建议**
   - 完整的中文版本内容结构（镜头、角色、场景、技术）
   - 与英文版本保持对应

**使用示例：**
```
用户："执行1-5号，用中文prompt"

LLM响应：
01. 【工业废墟中的洛可可幻梦】...

杰作，最佳质量，超写实照片，8K，超高清，中景镜头，
平视角度拍摄。一位东亚美女，拥有大而有神的眼睛，
白瓷般的肌肤...

（总计400+字符）
```

### 内容结构

#### 一、四大分类体系（含占比）

1. **萌系家居服（45-55%）**
   - 核心美学：反差萌的叙事逻辑
   - 代表单品：恐龙/库洛米/熊猫/狼连体衣、带尾巴卫衣
   - 材质：法兰绒、羊羔绒、珊瑚绒
   - 心理效应：激发保护欲、强调舒适感

2. **次文化特定风格（25-30%）**
   - 核心美学：身份认同的图腾
   - 细分：天使界隈 / 地雷系 / Y2K千禧风
   - 代表单品：淡蓝色卫衣、猫耳帽、粗线针织、荧光配饰
   - 色彩：淡蓝(Mizuiro)、黑粉配色、荧光色

3. **概念性角色摄影（15-20%）**
   - 核心美学：属性拟人化
   - 概念标签：怪兽幼崽、小恶魔、猫系少女、狐妖拟人
   - 要求：妆造统一、动作符合动物特征

4. **街头潮流配饰（10%）**
   - 核心美学：结构主义的重塑
   - 代表单品：结构化兽耳帽、混纺羊毛帽
   - 功能：重塑头型轮廓、改变头肩比例

#### 三、兽系穿搭法则

**法则1：层次堆叠法（Layering Strategy）**
- 适用：天使界隈、次文化风格
- 公式：超大卫衣 + 蕾丝内搭 + 短裙 + 过膝袜 + 兽耳帽
- 效果："上重下轻"对比

**法则2：解构穿法（Deconstruction Technique）**
- 适用：萌系居家、概念摄影
- 公式：连体衣拉链拉至腰部 + 露出内衣
- 效果：质感对比、视觉张力

**法则3：配饰化点缀（Accessorizing）**
- 适用：街头潮流、日常穿搭
- 公式：简约服装 + 兽耳帽（唯一异质元素）
- 效果：视觉破局点、高辨识度

---

#### 四、兽系摄影实务建议

**前景处理：**
- 材质呼应：绒毛球、羽毛
- 符号化介入：怪兽爪子模型
- 光效遮挡：彩色亚克力板

**中景处理：**
- 轮廓管理：S形曲线，避免呆板
- 交互实务：拉扯耳尖、遮住一只耳朵
- 对焦精度：锁定最近眼睛

**背景处理：**
- 生活化虚化：卧室场景
- 次文化色彩：淡蓝色LED灯管
- 几何背景：简洁墙面

---

#### 五、使用提示与禁令

**何时使用：**
- ✅ 萌系、可爱、反差主题
- ✅ 次文化风格
- ✅ 居家、休闲、日常叙事
- ✅ 需要辨识度的街拍

**何时避免：**
- ❌ 正式、职场、商务场景
- ❌ 过于严肃的主题

**禁令提醒：**
- 🔴 严禁真实动物耳朵、尾巴
- 🟡 狐狸元素是"显性元素"，避免过度使用

**频率控制（TERP）：**
- 每20个创意中不超过5-6次
- 优先探索：鹿、鹤、水獭、兔
- 避免刻板：猫耳 + 女仆装

# 🍬 Tongseoi Machine

### Sugar Water Machine · 糖水机

**一句话：它把「你觉得描述得很清楚」和「模型真正画出来」之间的那段差距，填上。**

---

## 🔍 同一个意思，两种命运

下面三组来自真实场景。左边是多数人的写法，右边是糖水机的写法。

### ① 「背对镜头」

```text
你写的：背对镜头
```

模型照做了：她转过身，**回头冲你笑**。

因为「背对」在模型眼里只是一个词，它不知道背面该有什么。

```text
糖水机要你写：
肩胛骨在薄纱下顶起两道浅棱，
后颈有一小截碎发被汗黏住，
衣料背面那道褶从肩线斜着落到腰侧，
她的视线落在画面左外，肩膀没有跟着头转。
```

这里没有出现「背对」，但每一句都只能从这个角度看见。

---

### ② 「情绪强烈」

```text
你写的：情绪强烈、氛围感拉满
```

模型给你的：眉毛皱起来、嘴角往下，标准的“悲伤脸”。

```text
糖水机要你写：
嘴角是压着的，没有往下撇；
下眼睑绷紧，卧蚕被顶得发亮；
眉心一道竖纹，鼻尖泛红但不是哭过；
她的下颌抬着，没有低头。
```

哪一种更像“真的在忍”，你可以立刻判断。

---

### ③ 「电影感」

这个词最没用，因为**它什么都可能指**。

```text
你写的：电影感、高级感、大片氛围
```

模型通常理解为：加暗角、加颗粒、调成青橙色调。

```text
糖水机要你写：
主光只从画面右侧那扇窄窗进来，在她左脸留一道硬边；
暗部靠背后那面白墙反上来的一点光托住，不是补光灯；
她的轮廓在背景上切出一道细亮线；
画面主调是灰蓝，只有唇上一点暖橘是对冲色。
```

**「电影感」不是形容词，是这四条的具体结果。**

## 📄 完整一条长这样

选中的方向展开成整段描述，结尾直接接相机参数：

> ……晾衣绳在逆光里绷成一条细黑线，床单被风鼓起来又落下，边缘扫过她的锁骨。机位压在胸口以下略仰，越过一整排滴水的白衬衫才够到她。她仰着头，右手还举在半空去够夹子，左脚脚跟离地，重心全压在右腿上…… Canon EOS R5 配 RF 85mm f/1.2L USM，平视偏低机位，f/1.8，1/500秒，ISO 200，白平衡 5200K，评价测光，眼部识别 AF，曝光补偿 -0.3EV，黑柔 1/8 滤镜，手持。

没有 `masterpiece, best quality, 8k, 超高清`。真实感由镜头、光圈和具体可见的东西承担。

## 🎯 为什么它能做到

因为它只做一件事：**把「评价」翻译成「证据」。**

「情绪强烈」是评价，「下眼睑绷紧、眉心一道竖纹」是证据。
「电影感」是评价，「主光只从右侧窄窗进来、暗部靠白墙反光」是证据。

评价是给同行看的，证据才是给模型看的。

**这条原则贯穿整套规则，剩下的都是它的展开。**

---

## 🛡️ 还有一件事：它不会改弱你的原稿

你给的是「暴雨中拉小提琴」。很多 AI 会在「安全舒适」的名义下改成：

```text
❌ 雨后的海边，空气湿润，她安静地演奏
```

更安全，更好看，**但已经不是你给的那个作品了。**

糖水机的判断只有一句：

> **这个天气是在「压迫」人物，还是在「伤害」人物？**
> **前者保留，后者规避。**

暴雨、巨浪、强风、雷电、浓雾、风雪都可以留——它们是天气，不是灾难。

## 🚀 开始

把 `Tongseoi Machine.md` 丢给任何支持 Skill / System Prompt / Custom Instructions 的 AI：

```text
给我 25 个"雨夜城市"的创意
```

挑几个，然后：

```text
执行 3、7、12
```

没有安装，没有依赖，没有 API Key。

---

## 🚫 这三种情况它帮不上

- **你只想一句话快速出图。** 它要求你先想清楚机位。
- **你偏好极简流程。** 它的规则很多，自检很多。
- **你的创意本身就是「什么样都行」。** 它是判定系统，判定需要靶子。
